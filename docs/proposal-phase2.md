## Phase 2：電話自動化のご提案

### 実現すること

- **電話の着信を自動で受ける**（24 時間 365 日）
- **音声をテキストに変換する**（Whisper API 使用）
- **既存の AI 分類フローに合流**
  → Slack の該当チャネルへ自動投稿
  → クレーム検知時は営業部長個人 LINE 即時通知（MVP と同等の SLA 5 分以内）

### システム構成

```
電話着信 → Twilio（050 番号） → 音声録音
    → Whisper API（音声 → テキスト）
    → 既存 AI 分類（Gemini） → Slack 投稿
    → クレーム時は営業部長 LINE Push（既存経路を再利用）
```

- **Twilio：** 050 番号取得・着信受付
- **Whisper API：** 音声 → テキスト変換（日本語対応）
- **既存システム：** AI 分類・Slack 投稿・LINE 通知（MVP の資産をそのまま再利用）

## 補足：Phase 2 の技術的な考慮事項

**MVP 導入直後の判断材料として：**

- 電話音声の Whisper API 変換精度は業界用語（物件名・地名）で 85〜95% 想定。分類ミスは MVP 同様「迷ったら要確認・その他」に流す安全側設計
- Twilio 050 番号は既存電話番号への転送でも導入可能（既存番号を変えずに済む）
- Whisper API のコストは **1 分あたり約 1 円**。月 50 件 × 平均 2 分 = 約 100 円 / 月。上記月額 5,000 円は Twilio 番号維持費 + 予備枠を含む
