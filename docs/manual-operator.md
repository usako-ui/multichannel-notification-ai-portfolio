# マルチチャネル通知システム 運用マニュアル

**対象：** 営業部長・現場スタッフ（非エンジニア）
**この 1 枚で日常運用が完結します。**

> **印刷推奨設定：** A4 縦・余白 15mm・フォント 10〜11pt（ブラウザで開き「印刷 → 詳細設定 → 用紙 A4・向き 縦・拡大縮小 90%」）

---

## 毎日の確認：Slack の 5 チャネルを開くだけ

| チャネル | 何が来るか | 対応目安 |
|---|---|---|
| `#賃貸` | 賃貸物件の問い合わせ | 当日〜翌営業日 |
| `#売買` | 売買物件の問い合わせ | 当日〜翌営業日 |
| `#内見` | 内見希望 | 当日中に日程調整 |
| `#クレーム緊急` | クレーム（🚨 マーク付き）| **5 分以内に確認・当日中に対応** |
| `#要確認` | AI が判断できなかったもの | 目視で判断・迷惑ならスルー可 |

**投稿の見方：** 1 行目に「送信元：LINE/Gmail｜送信者：〜さん」が付きます。誰からの問い合わせか一目で判別できます。

---

## 緊急通知（クレーム）

- クレーム検知 → **営業部長の個人 LINE に自動通知**（先頭に 🚨 マーク）
- **SLA 5 分以内**（実測 1 分未満）
- Slack `#クレーム緊急` にも同時投稿されるので現場も状況を共有可能

---

## おかしいと感じたら（障害対応）

**5 分待っても通知が来ないとき、以下の順で確認：**

1. **Slack の通知設定**（ミュート・通知オフ）を確認
2. **LINE 公式アカウントの通知設定**（ミュート）を確認
3. それでも来なければ **開発担当へ連絡**

**開発担当への連絡時に伝える 3 情報：**
- いつから通知が来ないか（例：今朝 9 時から）
- 最後に届いた通知の時刻（Slack や LINE の履歴から）
- 送信したメール / LINE の内容（件名・送信者）

---

## カテゴリ判定ルール（補足）

- **クレーム：** 「クレーム」「苦情」「至急」「緊急対応」「怒り」等のキーワード検出時。**迷ったらクレーム扱い（安全側）**。「クレームではありません」等の否定形は自動除外
- **賃貸 / 売買 / 内見：** AI（Gemini）が本文から自動判定
- **要確認・その他：** 上記に当てはまらない・迷惑メール・判断困難なもの
