## 1. はじめに

### このシステムでできること

LINE 公式アカウントや Gmail に届いた **お客様からの問い合わせを Slack に自動で振り分けます**。

- **通常の問い合わせ**（賃貸・売買・内見・その他）→ 自動的に対応するチャネルへ投稿
- **クレーム**（「苦情」「至急」「緊急対応」等のキーワード検出時）→ Slack のクレーム緊急チャネル + 営業部長 の LINE へ即通知

### 毎日やること

**Slack を開いて 5 つのチャネルを見るだけ**です。個別に LINE や Gmail を確認する必要はありません。

## 2. 日常の使い方

### 5 つの Slack チャネル

| チャネル名 | 何が投稿される | 対応の目安 |
|---|---|---|
| `#賃貸` | 賃貸物件の問い合わせ | 当日〜翌営業日 |
| `#売買` | 売買物件の問い合わせ | 当日〜翌営業日 |
| `#内見` | 内見希望の問い合わせ | 当日中に日程調整 |
| `#クレーム緊急` | クレーム・苦情（🚨マーク付き） | **5 分以内に確認・当日中に対応**|
| `#要確認` | 分類不能・迷惑メール・カテゴリ判断が難しいもの | 目視で判断・迷惑ならスルー可 |

### Slack 投稿の見方

投稿には **3 つの情報**が含まれます：

```
【賃貸】
送信元：LINE｜送信者：山田太郎さん

駅近の1LDKを探しています。家賃8万円くらいで空いている物件はありますか？
```

- 1 行目：**カテゴリ**（賃貸/売買/内見/クレーム/要確認・その他）
- 2 行目：**送信元と送信者**
  - 送信元：`LINE` か `Gmail` か
  - 送信者：LINE の表示名 or Gmail の From 表示名
  - 取得できない場合は「送信者：不明」と表示
- 3 行目以降：**問い合わせ本文**

### 送信者への返信方法

Slack から返信はできません。**送信元のチャネル（LINE or Gmail）で個別に返信してください。**

- 送信元が **LINE** の場合：
  1. LINE 公式アカウント管理画面（LINE Official Account Manager）を開く
  2. 「チャット」から送信者名を検索して個別チャットで返信
- 送信元が **Gmail** の場合：
  1. Gmail 受信トレイの「multichannel-inbox」ラベルフォルダを開く
  2. 該当メールを開いて「返信」ボタンで返信

## 3. 緊急クレームが来たとき

### 起きること（Slack + LINE の 2 系統通知）

お客様のメッセージに 「クレーム」「苦情」「至急」「緊急対応」「怒り」 等のキーワードが含まれると：

1. **Slack `#クレーム緊急`** に 🚨 マーク付きで即投稿されます
2. **営業部長の個人 LINE** にも即 Push 通知が届きます

### 営業部長の LINE に届く通知の例

```
🚨 クレーム検出
送信元：LINE｜送信者：山田太郎さん

エアコンが効きません。至急対応してください。苦情です。
```

### 対応の目安

| 時刻 | やること |
|---|---|
| 通知受信直後 | 送信者名と本文を確認 |
| 通知後 5 分以内 | Slack `#クレーム緊急` で内容を確認・担当者を決定 |
| 当日中 | LINE or Gmail の元スレッドで送信者へ返信 |

## 4. よくあるトラブルと対処法

### ケース A：営業部長 LINE に「⚠️ Slack通知が停止中です」が届いた

**届く通知の例：**
```
⚠️ Slack通知が停止中です

Slackへの投稿が3回連続で失敗しました。
今後の問い合わせがSlackに届かない状態です。

【原因】Slack Bot Tokenが無効・期限切れの可能性
【対応】開発担当者にBot Tokenの再取得と再設定を依頼してください

【技術詳細】invalid_auth
```

**何が起きているか：**
- Slack への通知投稿が失敗している状態です
- お客様からの問い合わせは受信できていますが **Slack に届いていません**
- Gmail・LINE には引き続き問い合わせは届いています

**やること：**
1. **⚠️ 通知本文の「【原因】」と「【対応】」を読む**（何をすべきかが書かれています）
2. **開発担当者に連絡**（[6. 困ったときの連絡先](#6-困ったときの連絡先)）
3. **メッセージ本文を開発担当者にそのまま転送**（「【技術詳細】」の情報が復旧に必要です）
4. 復旧までの間は LINE・Gmail を直接確認して個別対応

### ケース B：Slack のチャネルに投稿が全然来ない

**確認ポイント：**
- 営業時間内なら「お客様側の投稿が単純に少ない」だけの可能性が高い
- 半日以上何も来ない場合は [5. 問い合わせが届かない時の確認手順](#5-問い合わせが届かない時の確認手順3-ステップ) を実施

### ケース C：Slack のチャネルが見えない・アクセスできない

**やること：**
1. Slack アプリを最新版に更新
2. Slack ワークスペースに再ログイン
3. それでも解決しない場合は Slack 管理者（社内 IT 担当）に問い合わせ

### ケース D：クレーム緊急通知が営業部長の LINE に来ない

**やること：**
1. LINE アプリの通知設定を確認（マナーモード・おやすみモード解除）
2. LINE の対象公式アカウントをブロック解除
3. それでも来ない場合は開発担当者に連絡（LINE_MANAGER_USER_ID 設定確認が必要）

### ケース E：Slack に同じ問い合わせが 2 回投稿された

- 「システムの二重通知」ではありません
- お客様が同じ内容を **2 回別々に送信**したケースが大半（LINE ではメッセージ ID が異なる）
- 内容と送信時刻を確認して 1 件として対応してください

## 5. 問い合わせが届かない時の確認手順（3 ステップ）

**「Slack に何も来なくなった」と気づいたら、以下を順番に確認してください。**

### ステップ 1（1 分）：営業部長 LINE を確認

**確認ポイント：** 営業部長の個人 LINE に **「⚠️ Slack通知が停止中です」** の通知が来ていないか

- **来ている場合**：[ケース A の対応](#ケース-a営業部長-line-に-slack通知が停止中です-が届いた) を実施
- **来ていない場合**：ステップ 2 へ

### ステップ 2（3 分）：テスト送信を試す

**確認ポイント：** ご自身の LINE から公式アカウントに **テストメッセージ**を送ってみる

```
テスト送信です。1LDKを探しています。
```

- 送信後 **5 分以内**に Slack `#賃貸` に投稿されれば **システムは正常稼働中**（お客様側の投稿が少ないだけ）
- 5 分待っても投稿されない場合は ステップ 3 へ

### ステップ 3（即時）：開発担当者に連絡

**やること：** 以下の情報を添えて開発担当者に連絡

- ステップ 1・2 の結果
- 最後に Slack に投稿があった日時（Slack のチャネル履歴から確認）
- ご自身が送ったテストメッセージの送信時刻

## 補足：システムの動作イメージ

```
お客様 ──[LINE メッセージ]──▶ LINE 公式アカウント ──┐
                                                    │
お客様 ──[メール]───────────▶ Gmail ────────────────┤
                                                    ▼
                                       ┌──────────────────┐
                                       │ AI 自動分類       │
                                       │ （5 カテゴリ）     │
                                       └────────┬─────────┘
                                                ▼
                            ┌───────────────────┴───────────────────┐
                            ▼                                       ▼
                   通常の問い合わせ                          クレーム検出
                            │                                       │
                            ▼                                       ▼
                    Slack のいずれか                    Slack #クレーム緊急
                    #賃貸 / #売買 /                             +
                    #内見 / #要確認                     営業部長 個人 LINE Push
```

- **通常の問い合わせ：** LINE/Gmail 受信 → 数分以内に Slack 投稿
- **クレーム：** LINE/Gmail 受信 → **5 分以内**に Slack + LINE Push 同時通知
