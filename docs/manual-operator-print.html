マルチチャネル通知システム

運用マニュアル｜営業部長・現場スタッフ向け

A4・1枚版

1．毎日の確認：Slackの5チャネルを開くだけ

問い合わせは内容に応じて、以下のチャネルへ自動振り分けされます。

チャネル何が来るか対応目安
#賃貸賃貸物件の問い合わせ当日～翌営業日
#売買売買物件の問い合わせ当日～翌営業日
#内見内見希望当日中に日程調整
#クレーム緊急クレーム（🚨マーク付き）5分以内に確認・当日中に対応
#要確認AIが判断できなかったもの目視で確認
投稿の見方：1行目に「送信元：LINE/Gmail｜送信者：～さん」が表示され、問い合わせ元を確認できます。

2．緊急通知（クレーム）

🚨 クレームを検知した場合

  • 営業部長の個人LINEへ自動通知
  • Slack #クレーム緊急 にも同時投稿
  • 現場スタッフも同じ内容を確認できます

対応時間の目安

  • 目標：5分以内
  • 本課題での実測：1分未満
  • 🚨が付いた通知は優先して確認してください

3．5分待っても通知が来ないとき

Slackの通知設定
ミュート・通知オフを確認
LINE公式アカウント
通知設定（ミュート）を確認
開発担当へ連絡
①②で改善しなければ連絡
開発担当へ伝える3情報：①いつから通知が来ないか（例：今朝9時から）　②最後に届いた通知の時刻　③送信したメール・LINEの内容（件名・送信者）

4．カテゴリ判定ルール（補足）

クレーム
「クレーム」「苦情」「至急」「緊急対応」「怒り」等を検出。迷ったらクレーム扱い。「クレームではありません」等の否定形は自動除外。
賃貸 / 売買 / 内見
AI（Gemini）が本文から自動判定します。
要確認・その他
上記に当てはまらない、迷惑メール、判断困難なもの。
